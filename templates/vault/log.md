# Second Brain change log

This source template is not a record of live writes. See [[system/brain|the operating guide]]
and [[index|knowledge routes]].

When a future approved workflow supports log updates, record verified changes with
actual timestamp and timezone, operation, changed note links, source or receipt locator,
and verification result. Distinguish blocked, staged and conflicting outcomes from
published changes. Do not copy raw conversations, secrets or private source inventories
into this log. The current create-only workflow does not maintain it.
